Provider setup guide

How to configure your AI provider in Prompt Paul

To configure a provider in Prompt Paul: open Options, choose a connection profile, enter your provider's HTTP(S) endpoint, API key, and model, then save and send a test message in Chat. Use HTTPS for remote services; HTTP is mainly appropriate for a trusted local or private-network endpoint. It is a once-off setup unless you want to try different models.

1

Step 1: Open Prompt Paul Options

Open the extension menu from Chrome, select Prompt Paul, and open its Options page. The Get Started banner shows whether the selected connection is ready and includes an Open Chat button.

2

Step 2: Choose a connection profile

Select an existing profile or create a new connection. Prompt Paul supports an compatible API profile (OpenAI-compatible or Anthropic), a Codex subscription (ChatGPT) profile, and a Hermes Agent gateway profile.

3

Step 3: Configure the connection type

For an API profile, enter your provider's HTTP(S) endpoint, API key, and model. Prompt Paul supports OpenAI-compatible endpoints and the official Anthropic API endpoint. Use the model refresh control when available rather than relying on a fixed model name. A saved API key is masked and remains in place when you edit other fields.

For Codex, choose Sign in with ChatGPT; the extension discovers models for the connected subscription. Hermes uses a separate gateway URL and connection flow.

4

Step 4: Save the connection

Select Save Settings in the Connection section. Save the Privacy, Web Search, and Page Actions sections separately when you change those capabilities. If you leave with unsaved changes, Prompt Paul warns you before navigating away.

5

Step 5: Add optional capabilities

For API-key or Codex connections, add a Brave Search API key in Web Search Grounding if you want the Web toggle. In Current-Page Actions, you can optionally enable the bounded trusted mode. The per-run Act permission is enabled in the side panel; it is off by default and does not enable arbitrary browser automation.

6

Step 6: Open Chat and test

Select Open Chat, then try a selected-text action or load the current page. Use the side-panel status, model capability, and error message to troubleshoot before changing credentials. Keep API keys private and review approvals for any Hermes or Act-enabled run.
