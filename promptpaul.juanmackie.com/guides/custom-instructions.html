Custom instruction guide

Adding a custom instruction to Prompt Paul.

Give Prompt Paul instructions written for your workflow.

1

Step 1 — Open the configuration page

Open Prompt Paul Options from the extension menu, then open the Instructions section.

  • Select an existing connection or open Prompt Paul Options from Chrome's extensions menu.
  • Scroll to Instructions and choose New Instruction.
  • Save the section explicitly when you finish editing.
2

Step 2 — Write the instruction

In the “Instruction Name” field, give your custom instruction a name such as LinkedIn Outreach Message.

Next, describe what Prompt Paul should do when you use this custom instruction. For this example, you could write: 

Create a personalized LinkedIn message that establishes a connection and starts a conversation. Keep it:
- Personalized to the recipient’s profile and interests
- Professional, polished, relevant, and concise (one or two paragraphs)
- Focused on one clear call to action

Follow these guidelines:
- Greet the recipient by first name
- Introduce Prompt Paul briefly: “I am Prompt Paul, a Chrome extension that helps you use AI without leaving your workflow.”
- Explain the value: relevant, context-aware AI output; less repeated prompting through saved instructions; and accessible workflows for common tasks
- End with a clear call to action: “Try the Prompt Paul Chrome extension.”
- Sign off as Prompt Paul
3

Step 3 — Save the instruction

Click the save button. You should now find the custom instruction in your right-click context menu.
