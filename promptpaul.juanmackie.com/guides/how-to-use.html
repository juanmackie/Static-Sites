Quick start

How to use Prompt Paul to get AI answers in Chrome.

Install the extension, connect a model, select the context you want to process, and ask for an answer from the side panel or context menu. The shortest path is: install → connect → select → ask.

Use Prompt Paul in four steps

1

Install the Chrome extension

Add Prompt Paul from the Chrome Web Store, then open it from Chrome's Extensions menu or toolbar.

2

Connect an AI provider

Open Options, create or select a connection profile, enter the endpoint, API key, and model, then save and test it. For the exact fields, see the provider setup guide. You can also use Sign in with ChatGPT for a Codex subscription profile.

3

Select the context

Highlight text on any webpage and use the right-click action, or open the side panel. The composer can also hold page content, images, audio, video, and PDFs as removable context.

4

Ask for the result you need

Choose a quick action such as summarize, explain, proofread, or rewrite, or write your own request. Saved prompts can be reused through custom instructions.

Need current sources?

Enable Web only when live or verifiable information matters. If a search runs, Prompt Paul adds a source-linked Sources section. Read about web grounding and page actions.

Need a free or local setup?

Compare hosted and local options in the provider comparison, then use the API key guide for provider-specific starting points.
